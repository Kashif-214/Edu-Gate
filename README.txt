EDU SMART - Free starter project

WHAT THIS IS
A responsive education website and installable Progressive Web App (PWA).
It includes sample course cards, sample study notes, a 3-question quiz,
a student profile screen, and device-local quiz progress.

IMPORTANT LIMITATIONS
- This is a front-end starter/demo. It does not yet have real student accounts,
  admin upload tools, online payments, cloud database, or teacher dashboards.
- Quiz progress is stored only in the current browser/device.
- Do not upload private student information or copyrighted materials without permission.
- For PWA installation, the site must be served over HTTPS (GitHub Pages provides HTTPS).

PUBLISH FREE WITH GITHUB PAGES
1. Create/sign in to a GitHub account.
2. Create a NEW PUBLIC repository named: edu-smart
3. In the repository, choose Add file > Upload files.
4. Upload every file in this folder (index.html, styles.css, app.js,
   manifest.webmanifest, sw.js, icon.svg, README.txt). Upload the files,
   not the containing folder.
5. Commit the changes.
6. Open repository Settings > Pages.
7. Under Build and deployment, choose "Deploy from a branch".
8. Select branch "main" and folder "/ (root)", then Save.
9. Wait a few minutes. The website URL will be:
   https://YOUR-GITHUB-USERNAME.github.io/edu-smart/
10. Open that HTTPS URL in Chrome on Android. Use the browser menu
    > Install app or Add to Home screen, if available.

CUSTOMIZE
- Edit course titles and descriptions in app.js.
- Edit notes directly in index.html.
- Change colors and layout in styles.css.
